# 부모님 자유여행용 나트랑 3박 5일 일정표

50~60대 부모님 기준으로 **무리 없는 동선**, **큰 글씨**, **모바일 친화 UI**를 적용한 단일 웹페이지입니다.

## 구성 파일

- `index.html` : 일정표 전체 (HTML/CSS/JS 포함)

## 포함 기능

- 오늘 일정 전환 버튼: `Day 1 / Day 2 / Day 3 / Day 4~5`
- 오늘 일정 요약 자동 표시
- 일정 섹션 접기/펼치기(`details/summary`)
- 중요정보 박스 + 복사 버튼
- 준비물 실제 체크박스(브라우저 `localStorage` 저장)
- 비 오는 날 대체 일정
- 공항/환전/유심/그랩 팁

## 사용 방법

1. `index.html` 파일을 브라우저에서 열기
2. 상단 버튼으로 원하는 Day 선택
3. 준비물 체크 후 다음 접속 시 상태 유지 확인
4. 중요정보 복사 버튼으로 필수 정보 빠르게 공유

## 사용 대상

- 부모님 또는 중장년층 가족 여행
- 빠듯한 일정보다 **휴식 중심** 여행 선호
- 모바일로 일정 확인이 많은 사용자

## 권장 운영 팁

- 한낮(12~15시)에는 실내 일정/휴식 배치
- 이동은 그랩 중심으로 동선 단순화
- 식사는 너무 늦지 않게, 야간 일정은 짧게 운영
- 갑작스러운 비를 대비해 실내 대체 일정 우선 확보
